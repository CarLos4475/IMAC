## Uso y mantenimiento

Leer este índice y las referencias pertinentes antes de redactar o cambiar el diseño. Actualizar el archivo temático afectado y el estado general del contexto maestro después de avances sustantivos. Las instrucciones actuales del usuario prevalecen; si hay diferencias entre archivos, revisar su procedencia antes de resolverlas.

El archivo de capitulado conserva lo entregado. Una revisión posterior debe registrarse como revisión, no reescribir retrospectivamente esa entrega. Ningún pendiente se considera decidido por aparecer como título en el capitulado.
